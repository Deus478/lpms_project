# Feature requests
These are the high level user requests (not detailed system requirements) for what the LPMS should be able to perform. This software system is intended to support the functions of the legal department and company secretary. The system will enhance efficiency in case management, legal compliance, governance, record-keeping, and board management.


## System features

	
| **s/n** | **Feature**                         | **Details**                                                                                                                                                                                        |
| ------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1       | **Legal Case Management**           | ·         Register new cases with details (case number, parties, lawyer assigned, court).<br><br>·         Track deadlines, hearings, and outcomes.<br><br>·         Generate case status reports. |
| 2       | **Document Management**             | ·         Upload, store, and retrieve the legal documents.<br><br>·         Secure archiving.                                                                                                      |
| 3       | **Board and Committees Management** | ·         Generate meetings schedules.<br><br>·         Attendance tracking.                                                                                                                       |
| 4       | **Minutes and resolutions**         | ·         Record and archive minutes.<br><br>·         Track resolution implementation progress.                                                                                                   |
| 5       | **Reporting**                       | ·         Generate dashboards (pending cases, compliance status, legal advices, board decisions).                                                                                                  |
